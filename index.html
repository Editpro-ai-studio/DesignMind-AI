Install on this device

Install DesignMind once and open it from its own icon, in its own window. It works offline for trends, fabrics, colourways, repeats and projects.

  • Windows / Mac (Chrome or Edge): press Install app at the top, or the install icon at the right end of the address bar.
  • Android (Chrome): menu ⋮ → Install app (or Add to Home screen).
  • iPhone / iPad (Safari): Share button → Add to Home Screen.

Get a free Gemini key

Open aistudio.google.com/apikey, sign in with a Google account, choose Create API key, then paste it here. Free-tier limits are set by Google and can change.

Update trend research

Research is refreshed every week by the GitHub workflow in your repository. To run it now, open your repository, go to Actions, choose Update trend research and press Run workflow.
